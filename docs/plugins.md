# Plugins e ferramentas

Os plugins Zsh ficam em `dot_zsh_plugins.txt`. O Antidote regenera o bundle automaticamente quando esse arquivo muda.

## Oh My Zsh selecionado

- `git`: aliases e funções Git.
- `extract`: comando `x` para extrair arquivos.
- `web-search`: pesquisa pelo terminal.
- `colored-man-pages`: páginas de manual coloridas.

## Experiência interativa

- `zsh-autosuggestions`: sugestões baseadas no histórico.
- `zsh-history-substring-search`: busca do histórico com as setas.
- `zsh-syntax-highlighting`: realce de comandos válidos e inválidos.
- `zsh-completions`: completions adicionais.

## Binários

- `fzf`: busca interativa de arquivos e diretórios.
- `zoxide`: navegação inteligente com `z`.
- `eza`: `ls`, `ll` e `tree` modernos.
- `bat`: visualização de arquivos com syntax highlighting.
- `atuin`: histórico local avançado com `Ctrl-R`; sincronização é opt-in.
